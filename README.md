# 家庭物品收纳管理系统（登录注册创新版）

该版本可以上传到 GitHub，并通过 Render 部署为公开网址。

## 新增账号功能

- 独立登录页面
- 手机号和邮箱注册
- 手机号或邮箱登录
- 密码加密保存
- 安全退出登录
- 每位用户只能查看和管理自己的物品、购物清单和收纳位置
- 注册时验证手机号、邮箱和密码格式

## 原有创新功能

- 智能编号自动生成
- 收纳位置二维码
- 临期、过期和低库存提醒
- 家庭购物清单
- CSV 数据导出
- 浅棕色暖色家居风格

## 本地运行

```bash
python3 -m pip install -r requirements.txt
python3 app.py
```

浏览器打开：

```text
http://127.0.0.1:5000
```

首次打开会自动进入注册或登录页面。

## Render 部署

上传全部文件到 GitHub 后，在 Render 中连接仓库。项目中的 `render.yaml` 会自动配置：

- Build Command：`pip install -r requirements.txt`
- Start Command：`gunicorn app:app`

## 重要说明

该项目目前使用 SQLite。Render 免费服务重新部署或重启后，本地数据库可能被清空，因此适合作业展示。正式长期使用建议改用 PostgreSQL。


## 居住成员个性化

注册时可选择独居、情侣或已婚无子（两人）、已婚有子（三人及以上）。该信息仅用于个性化页面展示。


## 三种居住情况的个性化首页

- 独居：突出食品药品、日常消耗品、个人物品和有效期提醒。
- 情侣或已婚无子（两人）：突出共同用品、个人物品区分和共享购物清单。
- 已婚有子（三人及以上）：突出儿童用品、家庭常备药、学习用品和批量补货。

登录后，首页标题、说明、推荐管理类别和整理建议会根据注册时选择的居住情况自动变化。


## 儿童数量个性化

选择“已婚有子（三人及以上）”时，注册页面会显示儿童数量输入框。登录后，家庭首页会显示儿童人数，并生成儿童衣物、书籍、药品和学习用品的收纳建议。


## 儿童收纳新窗口

已婚有子家庭登录后，首页导航栏会出现“儿童收纳”。该页面会按照儿童数量自动生成独立区域，可分别添加和查看每名儿童的衣物、书籍、药品、玩具和学习用品。


## 稳定性修复

此版本会在每次请求前自动检查并补齐 `children_count`、`child_name` 等数据库字段。旧账号若没有儿童数量，会默认初始化为 1 名儿童，避免儿童收纳页面出现 500 错误。

登录后访问 `/diagnostic` 可检查当前数据库字段是否完整。
